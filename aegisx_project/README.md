# AegisX - AI Powered Penetration Testing Framework

## Features
- FastAPI backend
- Nmap scanning
- OWASP ZAP integration
- AI risk scoring
- Docker deployment
- PostgreSQL support
- React-ready frontend structure

## Installation

### Backend
```bash
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

### Docker
```bash
docker-compose up --build
```
